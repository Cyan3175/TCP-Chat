# TCP Chat 11.0

用 **WinUI 3（Windows App SDK）** 重写的桌面聊天客户端。

和 9.4 的 raylib 版最大的不同：**没有服务端**。程序把学校里已有的 **WebDAV 服务器**当作一块公共留言板 —— 每发一条消息就在远端目录里写一个 JSON 文件，每 2 秒列一次目录把新文件拉下来。不需要开端口、不需要装服务、不需要内网穿透。

**10.5 的变化**：**回车键分工修好**（`Enter` 发送，`Shift+Enter` 与 `Ctrl+Enter` 都是换行 —— 之前 `KeyDown` 收不到 Enter，因为 TextBox 自己先把 Enter 当换行处理掉了，现在改用 `PreviewKeyDown` 隧道事件）；**每收到一条新消息弹一个系统通知并让任务栏图标闪烁**；设置对话框改成**圆角**并跟随主题；修了浅色/深色下的文字可读性问题。**同时删掉了 10.3 / 10.4 的「液态玻璃」整套东西** —— 玻璃面板、彩色壁纸层、Win2D 折射后端、苹果式自绘开关与滑块，以及设置里的玻璃开关 / 质量滑杆 / 实现选择全部移除，界面回到 10.2 那种朴素的不透明面板；程序也不再依赖 Win2D。

**10.6 的变化**：**加入语音消息与文件传输**（📎 文件 / 🎤 语音两个按钮；图片、视频、音频、语音都在气泡里直接预览；文档类显示文件卡片，可打开/另存为）；**附件内容也走端到端加密**（设了密码时，服务器上只有密文，文件名/大小藏在密文里）；顺手修了底栏"最近同步"一直停在旧时间的问题。

**11.0 的变化**：**液态玻璃（Liquid Glass）**—— 把 `liquid-glass-WinUI` 那套 Win2D 实现移植进来，并加了质量滑块。

- **效果链**（移植自参考实现，逐级照搬）：背景采样 → **高斯模糊** → **湍流噪声**（Frequency 0.008 / Seed 92）→ **边缘遮罩**（噪声越靠边越弱，玻璃四周不会被撕开）→ **位移贴图**（用噪声推背景 = 折射）→ **叠色调** → **饱和度 / 对比度**，最后按圆角裁切并压一道高光
- **背景图**：优先用**系统桌面壁纸**（`TranscodedWallpaper`，读不到就退回注册表里的壁纸路径），都没有就**程序生成**一张彩色渐变（单文件 exe 不背素材）
- **玻璃面**：顶栏、输入栏、状态栏、以及**每一个消息气泡**都是独立注册的玻璃面（位置 + 圆角 + 色调），滚动/换行/缩放时自动重新量
- **质量滑块**（0~100，设置里拖动**实时生效**）：控制湍流层数（1~4）、模糊倍率（0.6×~1.15×）、是否做色彩增强、以及渲染分辨率上限（1.0×~4.0×）。实测窗口 1107×744、5 个玻璃面：质量 10 **3.7 ms**、质量 60 **4.3 ms**、质量 100 **5.1 ms**
- **开关**：关掉就回到 10.7 那种普通主题外观（画布隐藏、面板恢复主题色），开关与质量都写进 `settings.json`
- **修了浅色主题下自己的消息看不清**：自己的气泡以前是主题蓝 `#2B6CB0` 的 62% 透明度铺在折射背景上，浅色壁纸本来就亮，白字对比度只有 ~2.8:1；现在换成更深的蓝 + 更高不透明度，实测玻璃气泡平均色 `#275788`、**白字对比度 7.5:1**（WCAG AA 要求 4.5:1）
- **开关和滑块本身也是玻璃控件**：设置里的「液态玻璃」开关与质量滑块不再是系统控件，而是用同一套 Win2D 效果链自绘的玻璃药丸 / 玻璃滑轨（指针拖动、键盘空格都能操作）
- **性能取舍**：只在玻璃面位置变化时重画（不是每帧），滚出视口的面直接跳过；效果链按尺寸缓存复用（参考实现也是建一次后换 Source），避免每帧新建十几张中间纹理；色调平铺在玻璃上，保证文字清楚
- **稳定性**：玻璃相关的回调（绘制、量位置、气泡注册）全部包了异常保护 —— 画玻璃出问题最多是这一帧不画，不会把窗口带崩；另外 XAML 未处理异常现在会记进 `%LOCALAPPDATA%\TCPChat\crash.log` 并保持程序存活（老版本遇到就直接退出了）

**10.7 的变化**：

- **全套 Markdown 与扩展语法**：标题、粗体/斜体/粗斜体、~~删除线~~、`行内代码`、==高亮==、H~2~O / x^2^ 上下标、``` 围栏代码块（带语言标注与关键字着色）、有序/无序/嵌套列表、**任务列表** `- [x]`、**表格**（左中右对齐）、引用块、**GitHub 提示块** `> [!NOTE]`、分割线、链接与裸网址自动链接、图片`![]()`（自动下载显示）、脚注 `[^1]`、定义列表、`:::容器`、emoji 短代码 `:smile:`、行内/块级数学（原样等宽显示，不做 LaTeX 排版）。纯文本消息走快路径，**不会被当成 markdown**（`3 - 2 = 1`、`1.5 倍`、`a_b_c` 都保持原样）
- **字体应用到所有界面**：以前只有消息列表/输入框/状态栏跟着设置走，现在顶栏、按钮、右键菜单、下拉框、对话框（含设置里的字体列表）全部跟随；选了本机没装的字体会**自动退回系统默认并在底栏说明**，不会悄悄失效
- **数据目录换成 `%LOCALAPPDATA%\TCPChat\`**（原来是 `TCPChat10`）：第一次运行会把老目录里的 `settings.json` 与附件缓存**自动搬过来**，老目录随之清掉，昵称/主题/字体/加密密码原样保留
- **麦克风权限自动处理**：点 🎤 语音时先自动检查权限，没权限就弹窗并**直接打开系统的麦克风设置页**，用户打开开关回到窗口会**自动开始录音**，不用再点一次
- 修了**"麦克风权限明明是开的却录不了"**：录音前那个临时文件是用 `StorageFile.GetFileFromPathAsync` 拿的，而它**要求文件已经存在**（对新路径调用会直接抛 `FileNotFoundException` / 0x80070002），所以录音永远起不来；现在先把空文件建出来再交给 `StartRecordToStorageFileAsync` 写。录音失败时的提示也分开了：权限问题指路系统设置，其它问题给出错误码并提示检查输入设备
- 修了**浅色模式下自己消息上方的昵称和时间看不清**的问题（那两个颜色以前是按蓝色气泡算的，但它们是画在页面底色上的）
- 修了**切换主题后已经在屏幕上的消息没重新配色**的问题：气泡底色、正文字色、昵称/时间颜色都是算一次就存下来的 Brush，而气泡模板上的绑定是 OneTime —— 深色切浅色时老消息还留着深色那套颜色（浅底上浅灰字）看不清；现在绑定改成 OneWay，换主题时逐条重新取色
- 修了**同步周期**的两个问题：以前用 `PeriodicTimer` 固定周期、并且是“这一轮结束后再等 N 秒”，实际周期是 **N + 一轮耗时**（看起来就像周期多加了 1 秒）；而且在设置里改了周期**要重启才生效**。现在周期从“这一轮开始”算起（扣掉耗时），并且每轮都重新读设置 —— **改完立刻生效**；周期上限也和设置对话框对齐成 1~120 秒（原来内部按 60 秒截断，底栏显示的会和设置里填的不一致）

**设置文件位置**：`%LOCALAPPDATA%\TCPChat\settings.json`（系统统一位置）—— 早期 10.2~10.5 曾放在 exe 旁边，现在**不再往 exe 目录写任何东西**；第一次运行时会把 exe 旁边那份老设置自动搬进系统目录并删掉旧文件。

**10.2 的变化**：发布包变成**单个 exe**（不再是一堆文件的文件夹）；消息文件**直接写进你指定的目录**，程序不再自作主张新建文件夹；设置文件**直接放在 exe 旁边**；设置里**去掉了服务器认证（用户名/密码）**。

## 快速开始

1. 下载 `TCP-Chat-11.0.exe`，**放在哪个目录都行**，双击即可（自包含，无需安装 .NET 或 Windows App Runtime）
2. 首次启动会问昵称，填完即可开始聊
3. 默认连到 `https://dev.zhaohans.cn`，消息目录 `nw集训/学生资料临存`（消息文件就放在这一层，不再建"聊天"子文件夹）
4. **要保密就点「设置」→「端到端加密」，两边填一模一样的加密密码**

> - 配置文件在 **`%LOCALAPPDATA%\TCPChat\settings.json`**（崩溃日志也在同一个目录），exe 目录里不会再生成任何文件。
> - 从 **10.6 及更早**升级：老的 `%LOCALAPPDATA%\TCPChat10\`（设置 + 附件缓存）第一次启动会**自动搬到 `%LOCALAPPDATA%\TCPChat\`**，老目录清掉，昵称/主题/字体/加密密码原样保留。
> - 从 10.2~10.5 升级：如果 exe 旁边还留着老的 `settings.json`，也会**自动搬进系统目录并删掉旧文件**；从 10.0/10.1 升级则会把旧的默认目录 `…/学生资料临存/聊天` 改成上一级。

## 它是怎么工作的

```
  张三的电脑                     学校 WebDAV                   李四的电脑
 ┌──────────┐                 ┌────────────────┐              ┌──────────┐
 │ 发消息   │ ── PUT ───────▶ │ 学生资料临存/   │ ◀── PROPFIND │ 轮询     │
 │ (加密)   │                 │  msg_<时间>_<随机>.json        │ (每 2 秒)│
 │ 收消息   │ ◀─ GET ──────── │  {v,id,from,time,enc}          │          │
 └──────────┘                 └────────────────┘              └──────────┘
```

- **一条消息一个文件**：WebDAV 没有原子追加，所以不做"往一个日志文件里 append"，而是每条消息单独写 `msg_<unix毫秒>_<8位随机>.json`，天然无并发写冲突
- **文件直接放在你填的那个目录里**：不建子文件夹、不建日期目录。目录必须先在服务器上存在，程序**不会**自动新建（免得在你的共享目录里凭空多出一个文件夹）
- **文件名即排序键**：时间戳前缀让目录列表天然按时间有序
- **同步**：定时对消息目录发 `PROPFIND Depth:1`，只对没见过的文件名发 `GET`，收到后反序列化并插到正确的时间位置
- **撤回**：`DELETE` 自己的消息文件

### 端到端加密

| 项 | 说明 |
|---|---|
| 算法 | AES-256-GCM，带认证标签；密文被改动、被改名搬运都会解密失败 |
| 密钥 | `PBKDF2-HMAC-SHA256(密码, 盐, 100000 次)` → 32 字节；盐 = `SHA256("TCPChat10/v2|crypto|" + 消息目录)` 前 16 字节 |
| 每条的随机数 | 每条消息一个随机 96 位 nonce，同一句话发两次密文也不同 |
| 附加认证数据 | 消息文件名。密文被复制到别的文件名下就解不开 |
| 上传内容 | `enc` 字段 = `AESGCM1:` + Base64(nonce‖密文‖tag)，**服务器上不存明文正文** |
| 明文部分 | 昵称与时间仍是明文（接收方要靠它显示"谁、什么时候发的"）；正文与引用加密 |
| 密码不一致 | 该条消息显示 🔒「无法解密：本机的加密密码与发送方不一致」，底栏统计条数，不会显示乱码 |
| 换密码 | 设置里改完立即生效，程序会用新密码把服务器上的消息重新读一遍 |

**收发双方必须填完全相同的加密密码**（连大小写、空格都要一样）。这个密码只用来保护消息内容。

## 功能

### 消息
- 文本消息：`Enter` 发送，`Shift+Enter` / `Ctrl+Enter` 换行，输入框最高 170 DIP 自动换行
- **Markdown 渲染（10.7 起，11.4 补齐洛谷那套语法）**：标题 `#`、**粗体**、*斜体*、***粗斜体***、~~删除线~~、`行内代码`、==高亮==、H~2~O、x^2^、```代码块（语言标注 + 关键字着色，支持洛谷的 `line-numbers` 行号与 `lines=6-9` 高亮）、有序/无序/嵌套列表、`- [x]` 任务列表、表格（`:---` / `:---:` / `---:` 对齐，支持洛谷的 `^` 向上合并 / `<` 向左合并与 `::cute-table{tuack}`）、引用块、`> [!NOTE]` 提示块、`---` 分割线、`[文字](网址)` 与裸网址（点开用浏览器）、`![图](网址)`（自动下载显示，缓存在本地）、脚注 `[^1]`、定义列表、`:::容器`、`:smile:` emoji 短代码。**没写标记的消息不会被改动**（`3 - 2 = 1`、`1.5 倍`、`a_b_c` 原样显示），长消息超过 2 万字符自动退回纯文本以保证滚动流畅
- **LaTeX 公式排版（11.4）**：`$…$` / `\(…\)` 行内公式，`$$…$$` / `\[…\]` 块级公式；分数 `\frac`、根号 `\sqrt`（含 `\sqrt[n]{}`）、上下标、`\sum`/`\int`（块级时上下限叠放）、`\left(…\right)` 自动放大括号、`\begin{aligned}`/`cases`/`pmatrix` 等环境、`\boxed`、`\vec`/`\hat`/`\overline`、`\text{}`/`\mathbf{}`、常用希腊字母与运算符符号表；字体用 Cambria Math，分数线/根号/方框是画出来的（缩放不糊）；**代码块里的 LaTeX 不会被排版**；系统通知里显示可读的纯文本（`\frac{a}{b}` → `a/b`）
- **洛谷扩展语法（11.4）**：折叠框 `:::info[标题]` / `:::success` / `:::warning` / `:::error`（`{open}` 默认展开，可嵌套）、`:::align{center|right|left}` 对齐、`:::epigraph[——作者]` 引言；和洛谷一样**不解析原始 HTML**（标签按普通文字显示）
- **文件传输**：点「📎 文件」选任意文件上传，附件先传 `att_*` 再发一条引用它的消息；点气泡里的卡片/图片用系统程序打开，右键可「打开附件 / 另存为…」，撤回时附件一起删
- **语音消息**：点「🎤 语音」开始录，再点一下「停止」发送（`.wav`，气泡里显示时长与播放按钮，再点暂停）；**10.7 修好了"权限开着也录不了"**（见下）；**麦克风权限会自动处理**：点之前先查权限，没有就弹窗并打开系统的麦克风设置页，打开开关回到窗口会自动开始录音（10.7）
- **媒体预览**：图片直接在气泡里显示；**视频取第一帧当缩略图**并盖一个播放角标；**音频/语音**显示成播放条；其它类型显示文件卡片（图标 + 文件名 + 大小）
  > 实现说明：回车走 `PreviewKeyDown`（隧道）而不是 `KeyDown` —— TextBox 内部会先把 Enter 当成换行标记为已处理，普通 `KeyDown` 根本收不到；同时用 `handledEventsToo` 再兜一层"发送"，换行只由预览层负责（否则 Ctrl+Enter 会插两个换行）
- **新消息提醒**：收到别人发来的新消息时弹一个系统通知（标题=昵称，正文=消息内容），同时让任务栏图标闪几下；翻历史消息和自己发的不打扰。通知弹不出来（系统关了通知权限）时不影响收消息
- **引用回复**：右键消息 →「引用」，发送后显示为带左侧强调条的引用块（加密时与正文一起加密）
- **复制文本**：右键 →「复制文本」
- **撤回**：右键自己的消息 →「撤回（从服务器删除）」，从服务器删掉并同步移除
- 自己发的消息靠右蓝色气泡，别人发的靠左浅色气泡，各带发送者与时间；加密成功收到的消息带一把小锁 🔒
- 新消息自动滚到底部（可在设置里关闭）

### 界面
- 原生 WinUI 3 控件，跟随系统深浅色，也可在设置里强制浅色/深色
- **设置对话框是圆角的**，并且跟随主题（弹出层不继承窗口主题，所以是单独设的）
- 深浅色下的次要文字（发送者、时间、状态栏）、引用块、发送失败的红字都分别配过色：浅色下用深一点的灰、深色下用亮一点的灰，引用块跟随气泡正文颜色——不会出现深色下看不清、或者蓝气泡上压一行黑字
- **10.7 修**：浅色模式下**自己消息上方的昵称与时间**以前用的是半透明白（那是给蓝色气泡里的字配的），画在浅色页面底色上几乎看不见；现在这两个颜色跟随主题走了
- **字体列表**：设置里下拉选择本机已安装的字体（下拉项用它自己的字体实时预览），选中后立即应用，并写进 `settings.json`，下次启动照旧
- **字体应用到所有界面（10.7）**：顶栏、按钮、状态栏、输入框、消息气泡（含 markdown 正文）、右键菜单、下拉框、各种对话框全都跟着走；做法是"覆盖应用级字体资源 + 递归刷一遍可视树"，图标字体（Segoe MDL2 / Fluent Icons）不动。代码块保持等宽字体，方便对代码。选了本机没装的字体会自动退回系统默认并在底栏提示一句
- 顶栏显示连接状态灯与"已加密 / 未加密"，底栏显示消息条数 / 同步周期 / 上次同步时间 / 当前目录 / 是否有解不开的消息
- **缩放（11.4）**：`Ctrl +`（或 `Ctrl+Shift+=`、小键盘 `+`）放大、`Ctrl -` 缩小、`Ctrl 0` 回到 100%、**`Ctrl + 滚轮`** 也可以；60%~240%，10% 一档，**正文/代码块/表格/公式/昵称/时间一起缩放**（重排而不是放大图片），比例写进 `settings.json`，底栏提示当前百分比
- **程序图标（11.4）**：图标取自 [MahApps.Metro.IconPacks](https://github.com/MahApps/MahApps.Metro.IconPacks) 6.2.1 的 FontAwesome6 图标包 —— `CommentDotsSolid`（聊天气泡 + 三个点），生成多尺寸 `app.ico` 作为 exe / 窗口 / 任务栏图标，顶栏左上角也放了一个小图标
- **液态玻璃可读性（11.4 修）**：气泡玻璃色调改成「画的时候按当前消息取色」（列表回收气泡时原来的写法会把「自己/别人」判错 —— 自己的消息被画成白玻璃 + 白字，深色切浅色后整块看不见）；昵称/时间在玻璃模式下加了跟主题走的衬底与专用字色，压在壁纸上也读得清
- 高 DPI 感知（PerMonitorV2），窗口按 DIP 居中显示

## 编译

需要 **.NET 10 SDK** + **Windows 11 SDK 10.0.26100**（或 VS 2022 Build Tools 带 UWP/WinUI 工作负载）。

```powershell
cd TCPChat10
dotnet build -c Release                  # 调试构建产物(文件夹形式, 便于反复启动)
dotnet publish -c Release -o ..dist      # 发布: 只产出一个 TCP-Chat-10.7.exe
```

关键工程设置：

- `WindowsPackageType=None`（免打包运行，双击 exe 即用）、`WindowsAppSDKSelfContained=true`（把 Windows App Runtime 打进去，目标机不需要预装任何运行时）
- `PublishSingleFile` + `IncludeAllContentForSelfExtract` + `EnableCompressionInSingleFile`（发布成**单个 exe**；代价是首次启动会把自己解压到 `%TEMP%\.net\TCP-Chat-10.7\` 下，之后复用）
- 设置文件位置用 `Environment.ProcessPath` 定位 exe 目录 —— 单文件发布时 `AppContext.BaseDirectory` 指向的是 `%TEMP%` 里的解压目录，不能用
- `Markdig` 1.4.0（MIT）负责 markdown 解析，只有几百 KB，纯托管代码，单文件发布没问题

> WindowsAppSDK 版本必须 ≥ 2.5.1：1.7.x 上 `XamlCompiler.exe` 会静默退出码 1，构建直接失败。

## 已知限制与注意事项

- **加密只能保护正文**：昵称、时间、消息条数仍是明文，服务器管理员能看到"谁在什么时候发了多少条"。密码忘了就真解不开了（没有找回机制），换密码也不会重新加密历史消息
- **同一目录 + 同一密码 = 同一把钥匙**：密码是双方共享的口令，谁拿到密码谁就能解密；没有做每用户密钥对/前向保密
- **消息目录是公开的**：只要知道 WebDAV 地址和目录名，任何人不登录也能读到消息文件（加密后读到的是密文）。**不要在共享目录里发隐私内容**，除非开了加密
- **程序不会自动新建目录**：目录填错或还没建，会直接提示"聊天目录不存在"，消息不会写到别的地方去
- **单文件 exe 首次启动稍慢**：会把自己解压到 `%TEMP%\.net\TCP-Chat-10.7\`（约 240 MB，之后复用；换新版本会再解一份，旧的可以删）
- **消息不是实时推送**：靠轮询，默认 3 秒（1~120 秒可调，**改完立刻生效**；周期从每轮开始算，所以相邻两条“最近同步”的时间差就等于设置的周期），对方最多慢一个周期看到（服务器本身偶发会把某个请求挂住几十秒，客户端对每个请求都设了超时，卡住会自动跳过并在下一轮重试；发送失败会自动重试两次，仍失败会在气泡上标出 HTTP 状态）
- **历史只按文件名时间戳排**：客户端时钟不准会导致消息顺序错乱
- **附件与语音**：整份文件会先读进内存再上传（几十 MB 没问题，超大文件请直接用资源管理器拷）；附件按文件名缓存在 `%LOCALAPPDATA%\TCPChat\cache`（markdown 里的网图另有 `cache\mdimg`）；**设了加密密码时附件内容也是密文上传**（AES-256-GCM，消息文件名作为附加认证数据），密码不一致时对方只看到"解密失败"
- **液态玻璃**占一点 GPU：效果链是 Win2D 画的，玻璃面越多/质量越高越吃显卡（核显也能跑，实在卡就把质量拉到 30 以下或直接关掉）；**桌面被全屏程序盖住时**（比如玩游戏）窗口自己不受影响，但截图工具通常抓不到 Win2D 的内容
- **视频缩略图**用 WinRT `MediaComposition` 取第一帧，取不到就退回文件卡片；**语音录制**需要系统麦克风权限 —— 非打包程序没有"每个应用单独询问"的系统弹窗，只有「设置 → 隐私和安全性 → 麦克风 → 让桌面应用访问你的麦克风」这一个总开关，所以 10.7 会在点 🎤 时自动检查并直接把这个设置页打开
- **markdown 是「只读渲染」**：不执行 HTML（`<b>` 之类按原样显示，和洛谷一致），图片只支持 http/https 网址（本地路径不读文件）；单条消息超过 2 万字符自动退回纯文本渲染，避免滚动卡顿
- **公式支持的是常用 LaTeX 子集**：自定义宏（`\def`）、`\ce{}` 化学式、`\begin{tikzcd}` 之类没做；不认识的命令会**按原文显示**（不会把内容吞掉）
- **洛谷语法里没做的**：Bilibili 视频插入（当普通图片地址处理）、`[toc]` 目录；折叠框和洛谷一样默认收起，点标题展开
- **10.0 时期的老附件消息现在能正常显示**（不再被当成空气泡丢掉），里面的 `att_*` 文件也点得开

## 9.4 及以前（raylib 版）

仓库根目录的 `TCP Chat9.4.cpp` 是基于 [raylib](https://www.raylib.com/) 6.0 + Winsock2 的 C++17 单文件实现，**自带服务端**、走原始 TCP 直连（默认端口 45678），功能包括多房间、私聊、断点续传、表情、搜索、托盘等。

```powershell
g++ "TCP Chat9.4.cpp" -o TCP-Chat-9.4.exe ^
  -I"raylib/include" -L"raylib/lib" ^
  -lraylib -lws2_32 -lwinmm -lgdi32 -lopengl32 -limm32 -lcomdlg32 -lshell32 ^
  -static -static-libgcc -static-libstdc++ -mwindows ^
  -O2 -std=c++17
```

两版各有取舍：9.4 需要一台机器当服务器、但消息不落地；10.x 不需要服务器、消息存在共享目录里（10.1 起可以端到端加密）。历史版本见 [Releases](https://github.com/Cyan3175/TCP-Chat/releases)。
